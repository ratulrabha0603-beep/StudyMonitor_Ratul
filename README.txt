SMART STUDY MONITOR - MOBILE (runs in Chrome, started from Acode)

1. Unzip this folder on your phone (Files app > tap zip > Extract).
2. Open Acode > menu > "Open folder" > pick study-monitor-mobile.
3. Open index.html and tap the Run (play) button at the top right.
4. If the camera is blocked in Acode's preview, open the address Acode shows
   (http://localhost:8158/index.html) in Chrome instead.
5. Tap Start, allow the camera, prop the phone up. Only phone detection needs internet (small model download); face and eye monitoring work offline.

Files: index.html (screen), app.js (logic), sounds, face model and engine files (all in the same folder).
